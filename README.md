# 📊 Score Manager Basic

A lightweight Command Line Interface (CLI) application written in Python to manage student scores. This project demonstrates basic data structure management using Python lists and dictionaries.

## 🚀 Key Features

- [x] Add new student records containing Name and Score.
- [x] Display the complete list of all saved students.
- [x] Automatically calculate the class average score (GPA).

## 🛠️ Built With

- **Language:** Python 3.x (No external dependencies required)

## 📥 Installation & Usage

### 1. Prerequisites
- Ensure that **Python 3** is installed on your local machine.

### 2. Run the Application
Open your Terminal (macOS/Linux) or Command Prompt (Windows) and execute the following commands:

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project directory:
   ```bash
   cd Score-Manager-Basic
   ```
3. Run the script:
   ```bash
   python main.py
   ```
*(Note: Replace `main.py` with your actual filename if you named your code file differently).*
